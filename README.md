# IBONARIUM: KYIV — THE LAST SIGNAL (v5, білд v3.3 / кеш ?v=12)

16-бітна відкрита survival-гра про Київ. Статичний сайт — бекенд не потрібен.

## Склад паку (все потрібне для релізу — жодного файлу більше не вимагається)

| Що | Файлів | Примітка |
|---|---|---|
| index.html | 1 | сторінка, контрольно-пускова залі |
| style.css | 1 | стилі (внутрішніх url() немає) |
| js/ | 12 | palette, audio, sprites, assets, kenney, landmarks, letters, world, ents, sys, gfx, main |
| assets/ | 347 PNG | всі спрайти, які запитує js/assets.js |
| 1.jpg, logo.jpg | 2 | плакат і лого зі сторінки |
| CHANGELOG.txt | 1 | список правок v3.3 + інструкція деплою |

Звук — чистий WebAudio-синтез (audio.js), аудіофайлів немає і не потрібно.
Шрифт — Google Fonts CDN (потрібен інтернет; без нього фолбек на monospace).

## Деплой на новий репозиторій

1. Скопіювати ВЕСЬ вміст цієї папки в корінь нового репозиторію
   (index.html має бути в корені — це вимога GitHub Pages).
2. Settings → Pages → Source: гілка main, папка /(root) → Save.
3. Сайт підніметься за 1–2 хв. Перевірка: відкрити /CHANGELOG.txt —
   якщо він є, новий деплой підхопився.

## Швидка перевірка без деплою

IBONARIUM_v12_single.html (поруч, у папці download) — вся ця гра,
зібрана в один файл: JS/CSS і всі 347 ассетів зашито всередину (base64).
Відкрити подвійним кліком — і грати без сервера.
